the problem

what the export gets wrong

what you getwhat exportsnap writes
every file stamped with the download daythe capture date, in exif and in the file's own timestamp
captions as separate transparent pngsburned into the photo or video, scaled to fit
memories as uuids in one flat folder2021/03/20210304_143005.jpg
chat media with no sender, no conversationfiled per conversation, sender in the metadata
chat and snap history sitting in two json filesone transcript per conversation, four formats
media spread over five zip partsreconciled against the manifest, gaps counted

gps gets the honest treatment: the manifest's location field is a place name in every export seen so far, so exportsnap shows it as text and refuses to invent a coordinate from it. real coordinates get written, with the timezone offset.
